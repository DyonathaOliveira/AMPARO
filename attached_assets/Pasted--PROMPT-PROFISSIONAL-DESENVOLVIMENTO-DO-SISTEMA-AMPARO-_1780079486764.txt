# PROMPT PROFISSIONAL — DESENVOLVIMENTO DO SISTEMA AMPARO

Desenvolva um sistema web completo chamado **AMPARO**, focado na gestão de casas de repouso e cuidados com idosos.

O sistema deve possuir uma interface moderna, profissional, intuitiva, acessível e responsiva, com foco em usabilidade para cuidadores, enfermeiros e gestores.

IMPORTANTE:

* O projeto é acadêmico de Engenharia de Software.
* A aplicação deve ser totalmente editável.
* O código precisa ser organizado, componentizado e limpo.
* Utilize boas práticas de UX/UI.
* Desenvolva as telas com navegação funcional entre páginas.
* Os botões devem possuir interatividade real.
* O sistema deve simular funcionamento básico real.
* O layout deve transmitir confiança, cuidado, saúde, organização e segurança.
* O sistema deve funcionar bem em desktop e tablet.
* Seguir princípios de acessibilidade WCAG 2.1.

## OBJETIVO DO SISTEMA

O AMPARO é um software de gestão para casas de repouso.

O sistema deve auxiliar:

* cuidadores;
* enfermeiros;
* gestores;

nas rotinas de:

* administração de medicamentos;
* cadastro de residentes;
* atividades diárias;
* passagem de plantão;
* consultas;
* alertas;
* relatórios;
* acompanhamento do turno.
