# MIGRAÇÃO DO SISTEMA AMPARO PARA EXECUÇÃO NATIVA EM WINDOWS E PUBLICAÇÃO NO GITHUB

Atue como um Engenheiro de Software Sênior, Arquiteto de Sistemas, Especialista em Ambientes Windows, DevOps e Especialista em Migração de Aplicações.

Sua missão é adaptar o projeto atual do Sistema Amparo para que ele possa ser executado integralmente em ambiente Windows através do Visual Studio Code, sem qualquer dependência obrigatória do ambiente Linux ou da infraestrutura do Replit.

## OBJETIVO PRINCIPAL

Realizar todas as adaptações necessárias para que o sistema possa ser:

* Executado localmente em Windows 10 e Windows 11;
* Aberto e executado diretamente no Visual Studio Code;
* Mantido em desenvolvimento fora do Replit;
* Compartilhado com outros desenvolvedores Windows sem dificuldades;
* Publicado e atualizado no GitHub;
* Executado preservando 100% das funcionalidades atuais.

IMPORTANTE:

NÃO alterar:

* Interface do sistema;
* Regras de negócio;
* Fluxos operacionais;
* Banco de dados;
* Funcionalidades existentes;
* Estrutura lógica do produto.

O comportamento do sistema deve permanecer exatamente o mesmo.

As únicas alterações permitidas são as necessárias para garantir compatibilidade e execução em ambiente Windows.

# ETAPA 1 — DIAGNÓSTICO TÉCNICO

Analise integralmente o projeto atual e identifique:

* Dependências Linux;
* Scripts incompatíveis com Windows;
* Comandos Shell específicos;
* Arquivos .sh;
* Configurações do Replit;
* Dependências do replit.nix;
* Dependências de ambiente Unix/Linux;
* Configurações de paths incompatíveis com Windows;
* Bibliotecas que exijam substituição para compatibilidade.

Gerar um relatório técnico contendo:

* Problemas encontrados;
* Impactos;
* Solução aplicada;
* Justificativa técnica.

---

# ETAPA 2 — ADAPTAÇÃO PARA WINDOWS

Realize todas as correções necessárias para que o sistema funcione em Windows.

Verificar e corrigir:

## Paths

Substituir qualquer dependência de:

* /
* caminhos absolutos Linux
* referências incompatíveis

por soluções multiplataforma.

## Scripts

Converter scripts Linux para versões compatíveis com Windows.

Quando necessário:

* .bat
* PowerShell
* npm scripts multiplataforma
* Python multiplataforma

## Dependências

Garantir instalação automática através de:

* npm install
* pip install
* package manager correspondente

sem necessidade de configurações manuais complexas.
