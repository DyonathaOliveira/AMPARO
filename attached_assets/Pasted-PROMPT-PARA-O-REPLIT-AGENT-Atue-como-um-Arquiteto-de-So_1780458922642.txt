PROMPT PARA O REPLIT AGENT

Atue como um Arquiteto de Software Sênior, Engenheiro DevOps, Desenvolvedor Full Stack e Especialista em Migração de Aplicações.

Sua missão é transformar o projeto atualmente desenvolvido no Replit em uma aplicação totalmente independente da plataforma Replit, eliminando qualquer dependência de hospedagem, execução ou infraestrutura exclusiva do Replit.

Objetivo Principal

Realize uma análise completa do sistema existente e execute todas as adaptações necessárias para que a aplicação possa ser utilizada, executada, distribuída e mantida fora do ambiente Replit.

O resultado final deve permitir que o sistema funcione de forma autônoma em ambientes locais e externos.

Critérios de Aceitação

O trabalho somente será considerado concluído quando:

✅ O sistema não depender mais do Replit.

✅ O projeto estiver publicado no GitHub ou preparado para publicação.

✅ Houver documentação completa.

✅ Existir uma forma de execução offline.

✅ O ambiente puder ser reproduzido por qualquer desenvolvedor.

✅ Todas as funcionalidades existentes forem preservadas.

✅ Nenhuma informação do sistema original for perdida durante a migração.
